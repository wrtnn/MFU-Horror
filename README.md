# MFU CCTV Survival Horror

A browser-based survival horror game inspired by Mae Fah Luang University at night.

## Play the Game

🎮 [Play MFU CCTV Survival Horror](https://mfu-horror.vercel.app)

## Gameplay

- Survive from 12 AM to 6 AM.
- Monitor four CCTV cameras.
- Switch cameras using keys `1`, `2`, `3`, and `4`.
- Detect and eliminate ghosts using your flashlight.
- Hold the flashlight on a ghost for 1 second to eliminate it.
- Avoid ghosts before their 20-second countdown expires.

## Built With

- Next.js
- React
- JavaScript
- CSS

## Objective

Stay alert, monitor the cameras, eliminate anomalies, and survive until 6 AM!
